# 有序

一个手机优先的个人节奏工具：白天只看一个当前动作，晚上用一分钟收好今天。

## 使用

- **今天**：快速记录先进入收件箱，主动选一个动作开始。任务旁的“调整”提供缩小一步、重新选择和休息。
- **晚间复盘**：自动带出今天的进展，补充和下一步都可留空。结束当天不会把未完成任务全部推到明天。
- **课表**：按 2026 秋季新课表和周次生成；手机默认当天，可切换整周。午休、晚间休息各占独立行，跨休息的安排分段显示。
- **固定周安排**：2026/9/7—2027/1/17 每周安排课程预习作业、周五科研、周六计组及运动恢复，保留周三下午和周日空白。已有个人数据保留，首次升级自动加入，之后修改或删除不会被覆盖。课表的“本学期检查”逐周核对浏览器内的课程和个人安排，重叠卡片并排显示；第 8、9、12、17 周周五 6–7 节的数电与电子电路 2 预习复习冲突，保留原时段供调整。
- **项目**：保存当前进展、下一步、等待和暂放状态。习惯和完整截止列表收在二级入口。
- **截止提醒**：从用户设置的开始处理日期起提示；未设置时从截止当天提示。首页一次只显示一项，具体动作和日期可点开确认。
- **日期提醒**：当天和前一天打开首页会看到，前一天的晚间复盘也会带出。12 月 4 日买早饭会在 12 月 3 日提示提前设好早起闹钟。
- **主动推送**：设置内可选开启本机通知；需要先完成下方后台部署并配置服务地址。默认北京时间前晚 20:00、当天 07:00，仅推送日期备注，时间可改。未连接后台时会明确显示不可用，不把网页提醒伪装成推送。iPhone 需添加到主屏幕再开启。推送会受设备网络、省电和免打扰影响，不替代系统闹钟。
- **记录**：保留已完成动作、课程笔记、生活记录和历史复盘，没有连续打卡或每日配额。
- 设置菜单支持完整 JSON 备份和替换恢复。任务、项目和复盘只保存在当前浏览器，不跨设备同步。主动开启推送时，仅日期备注、发送时间和设备订阅上传到提醒服务；设备凭证不放入备份，换设备需单独开启。
- 升级时迁移旧记录并保留原始副本。旧学校课程统一为新课表，个人安排保留。再次统一课程可使用课表的“更新学校课程”。
- 支持 PWA；发布构建会预缓存准确的 JS/CSS 文件，首次联网加载完成后可离线使用。

## 开发与验证

使用 Node.js 22.16 或更高版本，执行 `npm ci`。`npm test` 检查周次、休息行、数据迁移、备份校验和复盘行为；`npm run check` 检查类型；`npm run lint` 检查代码。

GitHub Pages 构建为 `npm run build:pages`。本地可用 `node node_modules/vite/bin/vite.js --config vite.pages.config.ts --configLoader runner --host 127.0.0.1` 预览。

在线版本部署在 GitHub Pages。

## 推送服务部署

前端继续托管在 GitHub Pages；`push-worker/` 使用 Cloudflare Durable Object 持久化每台设备的订阅和待发送提醒，通过服务端 alarm 唤醒，即使网页关闭仍可发送。临时失败退避重试，过期订阅停止发送；关闭推送会取消后台任务。更改或删除备注时需联网同步，失败会明确提示。

1. `npx wrangler login` 登录自己的 Cloudflare 账户。
2. `npx wrangler deploy --config push-worker/wrangler.jsonc` 发布后台。
3. `node scripts/push-keys.mjs` 生成并上传 VAPID 密钥。私钥只保存在忽略的 `work/push-vapid.json` 和后台 secret 中，请安全保留它；不要随意轮换导致原订阅失效。
4. 将返回的 HTTPS Worker 地址填入 `app/push-config.json` 的 `serviceUrl`，重新构建发布前端。
5. 网站设置 → 开启本机主动推送 → 允许通知 → 发送测试通知。未获得浏览器授权前不会有系统通知。

本地后台验证：`node scripts/push-keys.mjs --local`，启动 `npx wrangler dev --config push-worker/wrangler.jsonc --port 8787` 后运行 `node tests/push-worker.integration.mjs`。集成验证会取消全部测试任务，不发送通知。不要把测试服务地址写入生产前端。
